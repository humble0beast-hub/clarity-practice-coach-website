# The Clarity Practice — Life Coach Website Demo

A responsive coaching website demonstration built with HTML, CSS and vanilla JavaScript.

## Preview locally

Open `index.html` in a browser. For the best local preview, use a simple static server such as VS Code Live Server.

## Deploy on Render

1. Create a new public GitHub repository, for example `clarity-practice-coach-website`.
2. Upload the contents of this folder to the repository root (so `index.html` is at the root).
3. In Render, choose **New + → Static Site** and connect the repository.
4. Set **Build Command** to blank and **Publish Directory** to `.`.
5. Deploy.

## Before presenting this as a portfolio sample

- Replace the Calendly placeholder URL in `index.html` (`https://calendly.com/your-link/intro-call`) with a real booking link you control. Until then, the booking button is a placeholder.
- The portraits are externally hosted Unsplash images. Replace them with properly licensed client-approved images or images you have permission to use before commercial delivery.
- The brand, coach identity and copy are fictional demonstration content. Do not present them as a real client project or claim the testimonials of a real person; this demo intentionally contains no fabricated client reviews.
- This is a custom-coded static website, not a WordPress installation. It demonstrates layout and front-end functionality. If a buyer orders a WordPress build, recreate the approved design in WordPress/Elementor and configure the buyer's actual booking system.
